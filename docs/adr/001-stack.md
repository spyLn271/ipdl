# ADR 001. Стек

**Решение.** Python 3.12 (FastAPI, SQLAlchemy 2, arq) для бэкенда, PostgreSQL 17 для реестра,
Next.js 16 для интерфейса — тот же стек и дизайн-система, что в Normocontrol AI.

**Почему.** Обработка текста, транслитерация, разбор XML и работа с LLM — сильная сторона
экосистемы Python; асинхронный FastAPI держит долгие запросы к сервисам без потоков.
PostgreSQL даёт транзакции, JSONB для портретов и pg_trgm для нечёткого поиска по реестру и
санкционным спискам — без отдельного поискового движка. Единый с Normocontrol фронтенд-стек
упрощает сопровождение. Качество: Ruff (широкий набор правил), mypy --strict, pytest с
интеграционными тестами на реальном PostgreSQL.
