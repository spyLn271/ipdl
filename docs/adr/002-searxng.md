# ADR 002. Поиск через собственный SearXNG

**Решение.** Открытые источники ищутся через собственный экземпляр SearXNG (JSON API) во
внутренней сети, без лимитера и без публикации наружу.

**Почему.** Метапоиск опрашивает несколько поисковиков за один запрос и сам исключает
недоступные (капча, блокировка) — нет зависимости от одного коммерческого API и ключей.
Запросы о лицах не уходят в сторонние сервисы аналитики поиска. Проверка с сервера (27.10.2026):
Google, DuckDuckGo (веб), Qwant, Mojeek блокируют; Brave, Yandex, Google CSE, Yahoo, Mwmbl,
Bing News, DuckDuckGo News, Yahoo News отвечают — они и оставлены в `deploy/searxng/settings.yml`.

**Последствия.** Поисковики меняют защиту от ботов — набор движков нужно периодически
пересматривать (предупреждение «Поисковики отвечали с ошибками» в портрете). Запросы
стартуют с интервалом 0,6 с: Brave ограничивает частоту.
