# ADR 003. Локальная LLM для извлечения фактов

**Решение.** Ollama с моделями Qwen3 (по умолчанию qwen3:8b, на CPU — qwen3:4b), режим
без «размышлений», строгая JSON-схема ответа, одна страница — один запрос.

**Почему.** Сведения о лицах — служебные: внешние LLM-сервисы исключены. Qwen3 хорошо
работает с русским и английским. Маленькая модель ошибается, поэтому вывод модели проверяется
кодом: обязательная дословная цитата, проверка категорий должностей (FIDE ≠ межгосударственная
организация), отсев «родства» без слов родства, описаний вместо имён, однофамильцев.
Подбор промпта (версия 3) — на реальных страницах: пустые «шаблонные» ответы исчезли после
добавления примера и правила «пустой массив вместо пустых элементов».

**Последствия.** На CPU портрет строится 3–4 минуты; модель — сменная
(`IPDL_LLM__PROVIDER=openai_compatible` для vLLM/llama.cpp).
