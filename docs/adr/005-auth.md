# ADR 005. Собственная аутентификация с сессиями

**Решение.** Пользователи и роли в PostgreSQL, Argon2id, серверные сессии (токен в httpOnly
cookie, в базе — хэш), CSRF по схеме double-submit, интерфейс и API на одном домене.

**Почему.** Портреты — служебная информация с разграничением доступа до уровня записи
(партнёр видит только переданное ему). Серверная сессия отзывается мгновенно (в отличие от
JWT). Внешний IdP при необходимости подключается перед прокси, не меняя модель ролей.
