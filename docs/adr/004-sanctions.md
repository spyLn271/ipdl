# ADR 004. Официальные санкционные списки вместо агрегаторов

**Решение.** Загружать первоисточники — XML ООН, OFAC SDN, ЕС (FSF), UK FCDO — ежедневно в
PostgreSQL и сравнивать имена своим алгоритмом.

**Почему.** Первоисточники бесплатны, юридически значимы и не требуют лицензии на коммерческое
использование (в отличие от агрегаторов с лицензией CC BY-NC). Имена в списках записаны в разных
романизациях (Viktar Uladzimiravich SHEIMAN / Viktor SHEYMAN), поэтому сравнение идёт по
«скелетам» имён с выравниванием романизаций, без учёта порядка слов и отчества; для компаний
отбрасываются правовые формы и общие слова.

**Последствия.** Национальные списки (например, Украины) не загружаются — их охватывает поиск
по СМИ. Добавить список = парсер в `sanctions/parsers.py` + запись в `sanctions-sources.yaml`.
