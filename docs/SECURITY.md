# Безопасность

Система обрабатывает персональные данные и сведения финансовой разведки. Модель угроз:
посторонний в интернете, пользователь-партнёр, пытающийся увидеть чужие записи, вредоносные
страницы в поисковой выдаче, утечка через логи и внешние сервисы.

## Доступ

* Нет анонимного доступа, кроме `GET /api/v1/meta`, `/healthz`, `/readyz` (без данных).
* Пароли — Argon2id (pwdlib), не короче 12 символов; после 5 неудачных попыток — блокировка
  на 15 минут; время ответа не выдаёт существование логина.
* Сессия — 256-битный случайный токен в cookie `HttpOnly; Secure; SameSite=Lax`, в базе — только
  SHA-256; срок 12 часов; смена пароля, отключение пользователя и смена роли отзывают сессии.
* CSRF — double-submit: изменяющие запросы требуют заголовок `X-CSRF-Token`, равный cookie
  `ipdl_csrf`; CORS не включается (интерфейс и API — один домен).
* Партнёр видит только лица и версии портретов, переданные его ПФР; на чужие записи — 404,
  а не 403 (не раскрывается факт наличия записи). Каждый просмотр партнёром — в журнале.

## Данные

* Модель — локальная (Ollama): тексты о лицах не уходят во внешние LLM-сервисы.
* Логи не содержат текстов страниц и ответов модели (`llm.log_dir` — только для отладки).
* Ответы API — `Cache-Control: no-store`; экспорт помечается «для служебного пользования».
* Журнал действий (`audit_events`) — вход/выход, неудачные попытки, создание и изменение
  записей, решения аналитика, экспорт, передачи партнёрам, поиск по спискам, администрирование.

## Загрузка страниц (SSRF)

Ссылки приходят из поисковой выдачи, поэтому загрузчик:
только `http(s)`, порты 80/443, без учётных данных в URL; имя хоста разрешается заранее и
все адреса должны быть публичными (запрещены loopback, RFC 1918, link-local, метаданные облака,
внутренняя сеть docker compose); редиректы проверяются заново; ответ ≤ 3 МБ; только HTML/PDF/
текст; `robots.txt` соблюдается. Остаточный риск — подмена DNS между проверкой и соединением.

## Разбор XML

Санкционные списки разбираются lxml без DTD, внешних сущностей и сети (тест на XXE).

## Контейнеры

Наружу публикуется только веб-интерфейс на loopback; API, база, Redis, SearXNG и Ollama — только
во внутренней сети. API и воркер — от непривилегированного пользователя, файловая система только
для чтения, `no-new-privileges`. Секреты (`POSTGRES_PASSWORD`, `SEARXNG_SECRET`) — в `.env`,
файл не коммитится.

## Зависимости

Версии зафиксированы (`uv.lock`, `pnpm-lock.yaml`, теги образов); CI выполняет `pip-audit`,
Dependabot предлагает обновления.
