# IPDL — реестр и аналитические портреты ИПДЛ

Система для подразделения финансовой разведки: по ФИО собирает открытые сведения о лице
через собственный метапоиск **SearXNG**, проверяет его по официальным **санкционным спискам**
(ООН, OFAC, ЕС, Великобритания), с помощью локальной языковой модели извлекает факты с
дословными цитатами и строит **аналитический портрет** — предварительную AML/KYC-оценку:
статус ИПДЛ по Закону РК № 191-IV, риск 0–100 по восьми факторам, связанные лица, хронология,
источники для верификации. Портреты хранятся в реестре, аналитик утверждает выводы, обмен
сведениями с зарубежными ПФР фиксируется в журнале обращений.

> Портрет — предварительный материал для комплаенс-проверки, а не официальное заключение.
> Каждый факт сопровождается ссылкой на источник и цитатой; решение принимает аналитик.

## Возможности

| | |
|---|---|
| Поиск открытых источников | SearXNG (Brave, Yandex, Google CSE, Bing/DDG/Yahoo News…), 17 запросов на лицо по темам: личность, должности, санкции, уголовные дела, негатив, связи, компании |
| Загрузка страниц | trafilatura (HTML), pypdfium2 (PDF), защита от SSRF, robots.txt, лимиты размера |
| Санкционный скрининг | официальные XML ООН, OFAC SDN, ЕС (FSF), UK FCDO — ежедневное обновление, нечёткое сравнение имён в любой транслитерации, сверка даты рождения; связанные лица и компании проверяются тоже |
| Извлечение фактов | локальная LLM (Ollama, qwen3) со строгой JSON-схемой; факт без дословной цитаты отбрасывается |
| Статус ИПДЛ | правила по пп. 3-3) ст. 1 Закона РК № 191-IV (абз. 6–8 — ИПДЛ и должностные лица межгосударственных организаций), меры п. 1 ст. 8 |
| Оценка риска | 8 факторов (должность, юрисдикция по спискам FATF и перечню льготного налогообложения, благосостояние, санкции, уголовные дела, СМИ, связи, операции в РК), прозрачные правила, «полы» по закону, версия методики в каждом портрете |
| Решение аналитика | переопределение статуса и уровней факторов с обоснованием, проверка источников, заключение; автоматический результат сохраняется |
| Реестр и обмен | версии портретов, журнал обращений, передача портрета зарубежному ПФР; партнёр видит только переданное |
| Экспорт | DOCX «Аналитический портрет» (структура образца предварительной AML/KYC-оценки) и PDF |
| Безопасность | роли (администратор, аналитик, наблюдатель, партнёр), Argon2id, сессии в httpOnly-cookie, CSRF, блокировка перебора, журнал действий |

## Быстрый старт (Docker)

```bash
cp .env.example .env                 # задать POSTGRES_PASSWORD и SEARXNG_SECRET
docker compose up -d --build         # web на 127.0.0.1:3000 (IPDL_WEB_PORT)
docker compose exec api ipdl users create admin --role admin
```

Воркер при первом запуске сам загрузит санкционные списки (≈ 35 с), `ollama-init` скачает
модель (`IPDL_LLM__MODEL`, на CPU рекомендуется `qwen3:4b`). Наружу сайт публикуется через
обратный прокси с HTTPS — см. [docs/DEPLOY.md](docs/DEPLOY.md).

## Разработка

```bash
uv sync                               # Python 3.12, зависимости
uv run ipdl db upgrade                # миграции (IPDL_DB__URL)
uv run ipdl sanctions update          # санкционные списки
uv run ipdl serve --reload            # API на 127.0.0.1:8000
uv run ipdl worker                    # воркер (Redis: IPDL_JOBS__REDIS_URL)
cd web && pnpm install && pnpm dev    # интерфейс
make check                            # ruff, mypy --strict, pytest
IPDL_TEST_DATABASE_URL=postgresql+asyncpg://… make test-db   # + интеграция с PostgreSQL
```

Портрет без реестра, из командной строки:
`uv run ipdl portrait "Иванов Пётр Сергеевич" --dob 1970-03-05 --docx portrait.docx`.
