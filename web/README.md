# IPDL — веб-интерфейс

Next.js 16 (App Router, standalone) для реестра и аналитических портретов иностранных публичных
должностных лиц. Дизайн-система — та же, что у Normocontrol AI: токены `src/styles/tokens.css`,
шрифты Inter и Geist Mono, компоненты `src/components/ui`, Gauge из Bklit UI.

## Страницы

| Путь                     | Кто видит                                  | Что делает                                                                                                                                                                                            |
| ------------------------ | ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/{locale}/login`        | все                                        | вход (cookie-сессия), возврат на исходную страницу (`?next=`)                                                                                                                                         |
| `/{locale}`              | все роли                                   | реестр: поиск по ФИО на любом языке, фильтры по статусу и уровню риска                                                                                                                                |
| `/{locale}/persons/new`  | admin, analyst                             | новая проверка → портрет строится в фоне                                                                                                                                                              |
| `/{locale}/persons/{id}` | все роли (партнёр — только переданные ему) | портрет: идентификация, статус ИПДЛ, оценка 0–100, факторы, хронология, связанные лица, санкции, источники с цитатами, журнал обращений; экспорт PDF/DOCX; решение аналитика; передача в ПФР партнёра |
| `/{locale}/sanctions`    | admin, analyst, viewer                     | состояние официальных списков, ручной скрининг                                                                                                                                                        |
| `/{locale}/methodology`  | все роли                                   | веса факторов, уровни, «полы», правовая основа, перечни FATF                                                                                                                                          |
| `/{locale}/admin`        | admin                                      | пользователи, зарубежные ПФР, журнал действий                                                                                                                                                         |

Локали: `ru` (основная), `kk`, `en` (для зарубежных партнёров).

## Безопасность

- Браузер обращается только к своему домену: `/api/v1/*` проксирует Route Handler
  `src/app/api/v1/[...path]/route.ts` на `API_URL` (читается при запуске). CORS не нужен.
- Сессия — httpOnly-cookie `ipdl_session`; изменяющие запросы несут `X-CSRF-Token` из cookie
  `ipdl_csrf` (double-submit, см. `src/lib/api/csrf.ts`).
- Ответы API не кэшируются (`Cache-Control: no-store`) — в них персональные данные.
- Права проверяет сервер; интерфейс лишь скрывает недоступные действия (`AuthGate`, `canEdit`).

## Разработка

```bash
pnpm install
API_URL=http://127.0.0.1:8000 pnpm dev      # бэкенд: `ipdl serve`
pnpm lint && pnpm typecheck && pnpm format:check && pnpm test && pnpm build
```

Фикстуры тестов (`src/mocks/*.json`) — настоящие ответы API: портрет публичного лица из
санкционных списков и методика.

## Docker

```bash
docker build -t ipdl/web .
docker run -p 127.0.0.1:3000:3000 -e API_URL=http://api:8000 ipdl/web
```

Образ без root (`nextjs:1001`), `HEALTHCHECK` на `/ru/login`.
